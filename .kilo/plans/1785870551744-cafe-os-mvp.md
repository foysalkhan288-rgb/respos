# Cafe OS Intelligence Agent — MVP Implementation Plan

**Plan ID**: `1785870551744-cafe-os-mvp`  
**Status**: Domains 1-8, 10 Complete — Domain 9 In Progress  
**Scope**: FOH order processing, KDS dispatch, custom modifier validation, inventory deduction, CRM loyalty, cash reconciliation, daily sales reporting, menu engineering, waste analytics, multi-branch sync, trend forecasting  
**Framework**: LangGraph + FastAPI + SQLite + OpenRouter

---

## 1. Goal

Deliver a LangGraph-backed POS intelligence layer that accepts JSON orders via REST API, validates custom modifiers, dispatches to KDS, deducts inventory in real time, and returns a strict schema-compliant response to the POS terminal.

---

## 2. Architecture

```
POS Terminal
   │
   │  POST /api/v1/orders  (JSON payload)
   ▼
FastAPI Server
   │
   │  invoke LangGraph graph
   ▼
LangGraph Orchestrator
   │
   ├── Node: customer_lookup      → CRM personalization + loyalty discount
   ├── Node: parse_order          → create order record
   ├── Node: validate_modifiers   → map custom tags → unit deductions
   ├── Node: calculate_totals     → subtotal, tax, discounts, total
   ├── Node: dispatch_kds         → emit KDS payload to kitchen
   └── Node: deduct_inventory     → subtract BOM units from stock
   │
   ▼
SQLite Database (orders, menu, inventory, modifiers, kds_orders, customers, shifts, daily_sales, waste_logs, branches, historical_sales)
MemorySaver Checkpointer (LangGraph state persistence)
```

**LLM**: OpenRouter API (optional, activated via `OPENROUTER_API_KEY` env var + `use_llm=True`)  
**Checkpointer**: `MemorySaver` (graph state persisted across node transitions)  
**Payment**: Mocked in MVP. `payment_status = "pending"` by default; no real gateway integration.

## 3. Data Models (SQLite Schema)

### `menu_items`
- `id` TEXT PK, `name` TEXT, `category` TEXT, `selling_price` REAL, `packaging_cost` REAL DEFAULT 0, `active` INTEGER DEFAULT 1

### `recipe_bom` (bill of materials)
- `id` TEXT PK, `menu_item_id` TEXT, `ingredient_id` TEXT, `unit_qty` REAL, `unit` TEXT

### `inventory`
- `id` TEXT PK, `name` TEXT, `unit` TEXT, `current_stock` REAL, `reorder_threshold` REAL DEFAULT 0, `cost_per_unit` REAL DEFAULT 0

### `modifiers`
- `id` TEXT PK, `keyword` TEXT, `ingredient_id` TEXT, `unit_qty` REAL, `unit` TEXT, `price_delta` REAL DEFAULT 0

### `orders`
- `id` TEXT PK, `counter_number` TEXT, `table_number` TEXT, `customer_id` TEXT, `subtotal` REAL, `tax` REAL, `discount` REAL DEFAULT 0, `total` REAL, `payment_status` TEXT DEFAULT 'pending', `payment_method` TEXT, `created_at` TEXT

### `order_items`
- `id` TEXT PK, `order_id` TEXT, `menu_item_id` TEXT, `quantity` INTEGER, `unit_price` REAL, `modifiers_json` TEXT DEFAULT '[]', `special_instructions` TEXT

### `kds_orders`
- `id` TEXT PK, `order_id` TEXT, `items_json` TEXT, `status` TEXT DEFAULT 'pending', `dispatched` TEXT

### `customers`
- `id` TEXT PK, `name` TEXT, `phone` TEXT, `reward_points` INTEGER DEFAULT 0, `preferences` TEXT

### `shifts`
- `id` TEXT PK, `cashier_id` TEXT, `started_at` TEXT, `ended_at` TEXT, `expected_cash` REAL DEFAULT 0, `actual_cash` REAL, `cash_difference` REAL, `payment_method` TEXT DEFAULT 'cash', `status` TEXT DEFAULT 'open'

### `daily_sales`
- `id` TEXT PK, `date` TEXT, `gross_revenue` REAL DEFAULT 0, `net_revenue` REAL DEFAULT 0, `tax_collected` REAL DEFAULT 0, `total_orders` INTEGER DEFAULT 0, `avg_basket_size` REAL DEFAULT 0, `cash_revenue` REAL DEFAULT 0, `card_revenue` REAL DEFAULT 0, `mobile_revenue` REAL DEFAULT 0, `top_item_id` TEXT, `top_item_quantity` INTEGER DEFAULT 0, `created_at` TEXT

### `waste_logs`
- `id` TEXT PK, `ingredient_id` TEXT, `quantity` REAL, `unit` TEXT, `reason` TEXT, `recorded_by` TEXT, `recorded_at` TEXT

### `branches`
- `id` TEXT PK, `name` TEXT, `location` TEXT, `manager_id` TEXT, `status` TEXT DEFAULT 'active'

### `historical_sales`
- `id` TEXT PK, `branch_id` TEXT, `date` TEXT, `gross_revenue` REAL, `net_revenue` REAL, `tax_collected` REAL, `total_orders` INTEGER, `avg_basket_size` REAL, `created_at` TEXT

## 4. LangGraph Graph Definition

```
State: TypedDict
  - order_id: str | None
  - counter_number: str | None
  - customer_id: str | None
  - raw_order_text: str | None
  - items: list[dict] | None
  - modifiers: list[dict] | None
  - subtotal: float | None
  - tax: float | None
  - total: float | None
  - payment_status: str | None
  - kds_payload: dict | None
  - inventory_deltas: dict | None
  - low_stock_alerts: list[str] | None
  - customer: dict | None
  - loyalty_discount: float | None
  - loyalty_points_threshold: int | None
  - error: str | None

Edges (sequential):
  customer_lookup → parse_order → validate_modifiers → calculate_totals → dispatch_kds → deduct_inventory → END

Optional branch (use_llm=True):
  llm_parse_order → customer_lookup → ...
```

## 5. Tools Registered

| Tool Name | Purpose | Output Schema |
|---|---|---|
| `create_order` | Insert `orders` row | `{order_id: str}` |
| `add_order_item` | Insert `order_items` row | `{item_id: str}` |
| `lookup_modifiers` | Map keywords → modifiers + price delta | `{matched: [], unmatched: []}` |
| `extract_modifier_keywords` | Extract modifier keywords from free text | `[str]` |
| `calculate_totals` | Deterministic subtotal + tax - discount | `{subtotal, tax, total}` |
| `dispatch_kds` | Insert `kds_orders` row | `{kds_id, status}` |
| `deduct_inventory` | Subtract BOM + modifier units from stock | `{deltas: {}, alerts: []}` |
| `get_menu_item` | Fetch menu item + BOM | `{menu_item, bom}` |
| `reconcile_shift` | Close shift, calculate cash difference | `{shift_id, expected_cash, actual_cash, cash_difference, flagged_for_review, status}` |
| `get_daily_sales_report` | Aggregate daily sales metrics | `{date, gross_revenue, net_revenue, tax_collected, total_orders, avg_basket_size, cash_revenue, card_revenue, mobile_revenue, top_item_id, top_item_quantity}` |
| `get_menu_engineering` | Compute profit margins + 4-quadrant matrix | `{matrix: {stars, puzzles, plowhorses, dogs}, summary: {total_items, avg_margin_percent}}` |
| `record_waste` | Log actual waste/spoilage | `{waste_id, ingredient_id, quantity, unit}` |
| `get_waste_analytics` | Compare actual vs theoretical consumption | `{waste_by_ingredient, theoretical_consumption, variance, high_variance_items}` |
| `get_branches` | List all branches | `{branches: []}` |
| `get_branch_sales` | Get sales for a branch | `{branch_id, days, sales: []}` |
| `get_branch_comparison` | Compare performance across branches | `{comparison: []}` |
| `get_forecast` | Sales forecast via rolling average | `{forecast: [], method, based_on_days, avg_daily_revenue, avg_daily_orders}` |
